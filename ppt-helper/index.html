강의 PPT 해설 도우미

진행 순서

  1. PPTX를 올리면 전체 페이지 수와 순서를 읽습니다.
  2. 1~5페이지부터 페이지마다 따로 보충 설명을 만듭니다.
  3. 필요한 항목만 체크하고 문장을 고칩니다. 검토를 마치면 다음 5페이지로 넘어갑니다.
  4. 배치 계획을 확인하고 결과 PPTX를 만듭니다. 원본 여백에 넣고, 모자라면 바로 뒤에 보충 슬라이드를 끼웁니다.
  5. 실제 결과 파일을 다시 읽어 그린 미리보기로 잘림·겹침을 확인한 뒤 내려받습니다.

    구형 .ppt 파일이라면

    PowerPoint에서 파일을 열고 파일 → 다른 이름으로 저장 → 파일 형식: PowerPoint 프레젠테이션(*.pptx)으로 저장한 다음 그 .pptx 파일을 올려 주세요. Google 슬라이드라면 파일 → 다운로드 → Microsoft PowerPoint(.pptx)를 쓰면 됩니다.
